# Social Events Finder

This is a project for the frontend education with Lexicon. The goal of this project is to showcase frontend development with the assistance of AI tools,
such as code reviewing, planning, etc.

---

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

This project uses [json-server](https://github.com/typicode/json-server/) to mock a backend API.

Data in the json for the server is from a dummy json file with data custom made to fit the purposes of this application.

## Installation

To view the webshop page, clone the repo, install dependencies and run a local development server.

```bash
git clone git@github.com:Amuga/social-events-finder.git
cd social-events-finder
npm install
npm run dev:full
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

The JSON server is running on [http://localhost:3001](http://localhost:3001). Here you can see the API endpoints and test them.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

## JSON Server Setup

This project uses [json-server](https://github.com/typicode/json-server/) to mock a backend API.

### Configuration

The server configuration files are located in the `data/` directory:

- `data/events.json`: The database file containing the evebts data.

### Scripts

The following scripts are available in `package.json`:

- `npm run mock-server`: Starts the json-server on port 3001.
- `npm run dev:full`: Runs both the Next.js development server and the json-server concurrently.

## API Endpoints

The mock server (running on port 3001) provides the following endpoints:

### Resources

- `GET/ /events`: Get all events
- `GET /events/:id`: Get a single event by ID
- `GET /categories`: Get all categories
- `GET /categories/:id`: Get a category by ID

### Create event

- `POST /events`: Create a new event

### Delete event

- `DELETE /events/:id`: Removes an event from the json file.

**Required Fields:**

- `Event title`: String
- `Category`: String
- `Date and time`: Date
- `Location`: String
- `Description`: String
- `Image URL`: String (local file relative URLs e.g. "/image2.png")
- `Expected attendees` - Number

**Auto-generated Fields:**

- `id`: generated by POST from json-server

### Pagination & Sorting (json-server)

See [json-server documentation](https://github.com/typicode/json-server/) for more information.

#### Pagination

Use `_page` and `_per_page` to paginate data:

- `GET /events?_page=1&_per_page=10` (First page, 10 items)
- `GET /events?_page=2&_per_page=10` (Second page, 10 items)

#### Filtering

- `GET /events?title:contains=Park` - Checks title fields for match.
